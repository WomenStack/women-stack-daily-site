Anthropic 发布 Claude Ship 测试版：智能体可审阅、修复并批准 PR（2026-11-23）

Anthropic launches Claude Ship in beta: agents that review, fix and approve pull requests (2026-11-23)

Anthropic 面向 Claude Team 与 Enterprise 计划的 GitHub 仓库推出 Claude Ship 测试版，把智能体编码从“写代码”延伸到“决定什么能合并”。包含三个智能体：已正式上线的 Code Review、测试版 PR Steward（修复失败的检查、合并冲突与审阅意见），以及测试版 Claude Approvals（按团队写在仓库里的自然语言策略文件批准常规改动——Anthropic 称之为更智能的 CODEOWNERS 文件）。开发者可用 Claude Code 里的新命令 /ship 试用；Anthropic 建议先以仅观察模式运行审批功能。在 Anthropic 自己的 Claude Code 团队，合并的 PR 从 6 月到 9 月翻了一倍多，被回滚的比例下降超 40%。符合条件的 Enterprise 客户可在 2027-01-15 前领取至少 1 万美元 Claude Ship 额度，按 token 计费。

Anthropic launched Claude Ship in beta for Claude Team and Enterprise plans on GitHub, extending agentic coding from writing code to deciding what merges. It bundles three agents: Code Review (already generally available), PR Steward (beta), which fixes failing checks, merge conflicts and review feedback, and Claude Approvals (beta), which approves routine changes under a plain-language policy file the team writes in the repo — Anthropic calls it a smarter CODEOWNERS file. Developers can try it with a new /ship command in Claude Code; Anthropic recommends running approvals in observe-only mode first. On its own Claude Code team, merged PRs more than doubled from June to September while the reverted share fell by over 40%. Eligible Enterprise customers can claim at least $10,000 in Claude Ship credits by 2027-01-15. Usage is billed on tokens.

Google DeepMind：Gemini 4 智能体团队找到更快的量子算法，每项都经 Lean 证明（2026-11-23）

Google DeepMind: Gemini 4 agent teams find faster quantum algorithms, each proved in Lean (2026-11-23)

Google DeepMind 与 Google Quantum AI 用 Gemini 4 智能体团队改进了多个著名量子算法，每项结果都用形式化定理证明器 Lean 证明。聚变能模拟的计算成本降低 11.8 倍，内存从 5650 个纠错量子比特降至 4338 个；光化学模拟便宜 8 倍；细胞色素 P450 药物代谢模拟便宜 2.5 倍；Grover 搜索变体快 2.57 倍；量子 arcsin 例程便宜 290 倍。各团队独立工作，用 Lean 验证想法，每四小时开一次虚拟会议交流。DeepMind 开源了 Lean 库、问题规约与已验证解。论文为 arXiv 2611.09822；一项独立审计从已发布文件复现了 headline 数字，但指出基线口径各有讲究（见“值得细读”）。

Google DeepMind and Google Quantum AI used teams of Gemini 4 agents to improve well-known quantum algorithms, with every result proved in Lean, a formal theorem prover. For a fusion-energy simulation the agents cut computing cost 11.8x and memory from 5,650 to 4,338 error-corrected qubits; photochemistry simulation got 8x cheaper; a cytochrome P450 drug-metabolism simulation 2.5x; a Grover search variant 2.57x faster; and a quantum arcsin routine 290x cheaper. The teams worked independently, verified ideas in Lean, and met in virtual conferences every four hours to trade ideas. DeepMind open-sourced its Lean library, problem specifications and verified solutions. The paper is arXiv 2611.09822; an independent audit found the headline ratios reproduce from the released files, with caveats about what the baselines measure (see Technical Reads).

思科与 OpenAI 推出 Shirudo，开源的自防御 Linux 安全项目（2026-11-23）

Cisco and OpenAI launch Shirudo, open-source self-defending Linux security (2026-11-23)

思科与 OpenAI 推出 Shirudo（日语“盾”），一个开源项目，让 AI 智能体以机器速度防御运行中的 Linux 系统。基于 eBPF，智能体可以发现漏洞、编写临时“护盾”封堵攻击路径，并在不中断服务、不重启的情况下先行测试——只有证据表明安全时护盾才上线，且每个护盾都经加密签名、通过 TPM 验证后加载。测试中，一个由 Codex 生成的护盾在不重启的情况下封堵了针对运行中 Elasticsearch 实例的 Java4Shell 攻击。这是思科旗下 Isovalent 的 Tetragon 运行时的重写版，专为智能体设计，采用 BSD 2-Clause 许可。项目尚处预发布阶段，未达到生产可用。

Cisco and OpenAI launched Shirudo (Japanese for "shield"), an open-source project that lets AI agents defend running Linux systems at machine speed. Built on eBPF, it lets agents find a vulnerability, write a temporary "shield" that blocks the exploit, and test it without disrupting the service or rebooting — the shield only goes live when evidence says it is safe, and every shield is cryptographically signed and verified via TPM before loading. In tests, a Codex-generated shield blocked a Java4Shell exploit against a running Elasticsearch instance without a restart. It is a rewrite of Cisco-owned Isovalent's Tetragon runtime, redesigned for agents, licensed BSD 2-Clause. The project is pre-release and not ready for production.

Anthropic 开放 Enterprise Frontier Safeguards 公开测试，零数据留存下仍可监测滥用（2026-11-23）

Anthropic opens Enterprise Frontier Safeguards in public beta, keeping misuse detection with zero data retention (2026-11-23)

Anthropic 向符合条件的企业开放 Enterprise Frontier Safeguards（EFS）公开测试。该系统把零数据留存与跨多次请求的自动化滥用监测结合：提示词、回复与推理过程经加密后存放在客户自己的云账户（Amazon S3 或 Google Cloud）中，Anthropic 的软件在那里扫描跨多次无害请求拆分的攻击模式，发现问题后通知客户自己的安全团队。Anthropic 与 100 多家客户共同开发了 EFS，包括 Bridgewater、Salesforce 与 Stripe。现已支持 Claude Platform、AWS 上的 Claude Platform、Amazon Bedrock 与 Google Cloud 上的 Claude；Microsoft Foundry 支持随后推出。Anthropic 不收 EFS 费用。

Anthropic opened Enterprise Frontier Safeguards (EFS) in public beta for eligible businesses. The system pairs zero data retention with automated monitoring for misuse across multiple requests: prompts, responses and reasoning are encrypted and stored in the customer's own cloud account (Amazon S3 or Google Cloud), and Anthropic's software scans them there for attack patterns split across many harmless-looking requests — flagging concerns to the customer's own security team. Anthropic developed EFS with more than 100 customers, including Bridgewater, Salesforce and Stripe. It is available on the Claude Platform, Claude Platform on AWS, Amazon Bedrock and Claude on Google Cloud; Microsoft Foundry support is coming later. Anthropic charges no EFS fee.

OpenAI：GPT-6 模型在实验室中设计出蛋白质，五项靶点均有结合证据（2026-11-24）

OpenAI: GPT-6 models design proteins in the lab, with binding across five targets (2026-11-24)

OpenAI 发布预印本《GPT-6 as a Universal Foundation Model for Protein Biology》，给出湿实验室验证：GPT-6 模型仅凭推理与通用代码就具备内在的蛋白质设计能力，无需调用专门的生物学模型来生成设计。在与合作方 Onava 的实验室测试中，322 个 GPT-6.2 迷你结合蛋白设计中有 35 个结合了靶点（10.9%，覆盖五个蛋白），182 个重新设计的抗体环中有 128 个结合 IL-4Rα（70%）。论文对局限毫不含糊：专门模型仍负责提供序列与筛选候选，整体蛋白质结构预测很弱（TM-score 0.38，对比 ESMFold2 的 0.93），部分基准分数可能反映记忆效应，而结合只是早期步骤——不是药物。该预印本未经同行评审。

OpenAI published a preprint, "GPT-6 as a Universal Foundation Model for Protein Biology", showing wet-lab validation that GPT-6 models have intrinsic protein-design capabilities using reasoning and general-purpose code, without calling specialised biology models to generate designs. In lab tests with partner Onava, 35 of 322 GPT-6.2 minibinder designs bound their targets across five proteins (10.9%), and 128 of 182 redesigned antibody loops bound IL-4Rα (70%). The paper is careful about limits: specialised models still supplied sequences and filtered candidates, whole-protein structure prediction is weak (TM-score 0.38 vs 0.93 for ESMFold2), some benchmark scores may reflect memorisation, and binding is only an early step — not a drug. The preprint has not been peer reviewed.
