OpenAI — OpenAI for Chile partnership with the Chilean government

Anthropic —《Claude Code 团队如何看待验证》（2026-11-16）

Anthropic — "How the Claude Code team thinks about verification" (2026-11-16)

The Claude Code team — where about 90% of the code is now written and reviewed by Claude — explains how it verifies agent work with evidence instead of just reading diffs. Three test types are worth investing in: end-to-end tests (hard to fool, with a definitive done criterion), property tests (invariants, round-trips, idempotency, checked with thousands of generated inputs) and differential tests (old system as oracle for migrations). In practice: verification means running the change end to end, codified in a verify skill in .claude/skills/; a failing check gets three fix rounds before a human is pulled in; code owners write their own checks; a 39-item reliability checklist triggers on diffs; changes can't modify the checks that judge them (REVIEW.md is read from the base branch); and new gates start in observe mode. A separate grader checking work against a rubric improved task success by up to 10 points in internal testing, and the team says giving an agent a way to verify its work makes the outcome two to three times better.
