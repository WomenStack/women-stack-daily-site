Google DeepMind — Gemini 4 Neon，更快的中端模型，面向编码、分析与 agent

Google DeepMind — Gemini 4 Neon, a faster mid-tier model for coding, analysis and agents

Google DeepMind 于 2026-11-18 发布 Gemini 4 Neon，定位在 Carbon 与 Hydrogen 之间，面向复杂软件工程、知识工作与科学工作流，更快也更便宜。定价为每百万输入 token 3 美元、每百万输出 token 15 美元，缓存输入 0.15 美元，上下文窗口 100 万 token。谷歌称 Neon 在 Artificial Analysis 编码 Agent 指数上排名第一、综合智能指数排名第三（61 分），每任务成本比 Carbon 低约 32%。即日起可通过付费版 Gemini API、Google AI Studio、Android Studio、Google Antigravity 以及 Gemini 应用（Pro 与 Ultra 订阅）使用。这是约一个月内第四款 Gemini 4 模型，此前已有 Argon、Carbon 与 Hydrogen。

Google DeepMind released Gemini 4 Neon on 2026-11-18, a faster mid-tier model sitting between Carbon and Hydrogen for complex software engineering, knowledge work and science workflows. It is priced at $3 per million input tokens and $15 per million output tokens, with cached input at $0.15, and a 1-million-token context window. Google says Neon ranks No. 1 on the Artificial Analysis Coding Agent Index and No. 3 on the overall Intelligence Index with a score of 61, and costs about 32% less per task than Carbon. It is available now through the paid Gemini API tier, Google AI Studio, Android Studio, Google Antigravity and the Gemini app for Pro and Ultra subscribers. Neon is the fourth Gemini 4 model in about a month, after Argon, Carbon and Hydrogen.

ggml-org — llama.cpp 与 ggml 达到 1.0.0，公共 API 稳定（2026-11-13）

ggml-org — llama.cpp and ggml reach 1.0.0 with a stable public API (2026-11-13)

llama.cpp 与 ggml 于 2026-11-13 达到 1.0.0 版本，这是三年半来的首个大版本。两个库现遵循语义化版本：大版本号变更将标志公共 C API 与 ABI 的破坏性变化。1.0.0 本身移除了已弃用的公共 API 函数，将 NextN 推测解码 API 提升为公开的 llama.h，新增 FP8 键值缓存，在服务器暴露于网络时加固 llama-server 以防 SSRF、跨域与 DNS 重绑定攻击，并新增兼容 OpenAI 的 /v1/audio/speech 端点。这是一个稳定性里程碑，而非速度里程碑——公告未给出性能数据。

llama.cpp and ggml reached version 1.0.0 on 2026-11-13, their first major release after about three and a half years. Both libraries now follow semantic versioning: major bumps will mark breaking changes to the public C API and ABI. The 1.0.0 release itself removes deprecated public API functions and promotes the NextN speculative-decoding API into the public llama.h, adds FP8 key-value caches, hardens llama-server against SSRF, CORS and DNS-rebinding attacks when exposed on a network, and adds an OpenAI-compatible /v1/audio/speech endpoint. The release is a stability milestone, not a speed one — the announcement gives no performance figures.
